# PORTRAIT ATLAS ✳

**전신 스탠딩의 얼굴 표정 차분을 한 번에 모아 이름을 붙이고, 포트레이트 도감으로 내보내는 브라우저 웹앱입니다.**

[웹앱 열기 (GitHub Pages)](https://sea-anemone17.github.io/PORTRAIT-ATLAS/) · [소스 코드](https://github.com/sea-anemone17/PORTRAIT-ATLAS)

> GitHub Pages를 아직 켜지 않았다면 아래 **배포 설정**을 먼저 완료하세요.

## ✨ 주요 기능

- **전신 스탠딩 1장**과 **표정 차분 수십~수백 장**을 업로드할 수 있습니다.
- 전신 이미지에서 얼굴을 **드래그하여 한 번만 지정**하면 모든 차분에 동일 좌표로 일괄 크롭합니다.
- 표정 이름은 자동으로 지어 주지 않습니다. **각 표정명은 사용자가 직접 편집**합니다.
- 표정 카드 드래그 또는 ↑↓ 버튼으로 순서를 조정하고, 파일명 기준 자연 정렬을 할 수 있습니다.
- 왼쪽에는 기본 전신, 오른쪽에는 얼굴 표정 격자를 놓는 **도감 레이아웃**입니다.
- **페이지당 12/20/30/40/48개**, 4/5/6/8열, 와이드(2560×1440) 또는 A4 가로(3508×2480), 라이트/다크 테마를 지원합니다.
- 기본 전신을 전체 페이지에 반복하거나 첫 페이지에만 표시할 수 있습니다.
- **현재 페이지 PNG** 또는 **전체 페이지 PNG ZIP** 내보내기를 지원합니다.
- 이미지가 포함된 **.patlas 프로젝트 파일**을 저장하고 다시 열 수 있습니다.
- 브라우저의 **IndexedDB에 자동저장**합니다. 단, 기기 저장 용량이 부족하거나 방문 데이터가 지워지면 사라질 수 있으니 .patlas 백업을 권장합니다.

## 🚀 사용 방법

1. **기본 전신 스탠딩**을 업로드합니다.
2. **표정 스탠딩 일괄 추가**에서 PNG 파일 80장 등을 한 번에 선택합니다.
3. **얼굴 영역 지정** 캔버스에서 얼굴을 드래그합니다. X/Y/너비/높이(%) 값을 직접 조절할 수도 있습니다.
4. 하단의 **표정 이름 붙이기**에서 표정명을 입력하고 순서를 조절합니다.
5. 페이지 크기와 페이지당 표정 개수를 조절하고 미리보기를 확인합니다.
6. **현재 페이지 PNG** 또는 **전체 페이지 ZIP**을 다운로드합니다.
7. 나중에 이어서 작업하려면 **프로젝트 저장**으로 `.patlas` 파일을 보관하세요.

**팁:** 전신 스탠딩과 차분 파일의 이미지 크기 및 얼굴 좌표가 같을 때 가장 정확하게 동작합니다. 서로 다른 크기의 파일을 함께 사용하면 일괄 크롭 좌표가 어긋날 수 있습니다.

## 🌐 GitHub Pages 배포 설정

이 저장소는 별도의 빌드나 서버 없이 실행되는 **순수 HTML/CSS/JavaScript** 프로젝트입니다.

1. 이 GitHub 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 고릅니다.
3. **Branch: `main`**, **Folder: `/(root)`**로 선택하고 **Save**를 누릅니다.
4. 배포가 완료되면 **https://sea-anemone17.github.io/PORTRAIT-ATLAS/** 주소로 접속합니다.

(처음 배포 직후에는 반영에 약간 시간이 걸릴 수 있습니다.)

## 🔒 개인정보와 파일 보안

- 업로드한 이미지는 GitHub 저장소나 외부 서버에 자동 전송되지 않습니다.
- 모든 이미지 처리는 **사용자의 브라우저에서 로컬로 실행**됩니다.
- 브라우저 저장은 사용 중인 기기의 IndexedDB에 보관됩니다.
- 프로젝트를 외부로 공유하려면 이미지가 포함된 `.patlas` 파일을 직접 전달해야 합니다.
- 페이지 배포가 공개여도 사용자가 올린 캐릭터 이미지 자체가 자동 공개되지는 않습니다.

## 🧩 프로젝트 구조

```text

└── README.md
```

별도 설치나 계정 가입이 필요하지 않습니다. Chrome 또는 Edge 최신 버전을 권장합니다.
